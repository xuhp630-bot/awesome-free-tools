## Development Utilities

- [Arabizi.io](https://arabizi.io) — Free, browser-based Arabic keyboard with real-time phonetic transliteration. Instantly converts Latin-script (Arabizi numbers/letters) into Arabic characters entirely client-side.
- [Codeshot.io](https://codeshot.io) — Turn code, logs, and terminal sessions into beautiful, syntax-highlighted pictures. Supports 18+ programming languages, custom themes, premium fonts, and high-res PNG/SVG export with zero watermarks.
- [DBDiagram.io](https://dbdiagram.io) - Tool for drawing database entity-relationship diagrams from a text syntax.
- [DevToys](https://devtoys.app) - Offline desktop toolbox with encoders, formatters, and generators for developers.
- [Hoppscotch](https://hoppscotch.io) - Open-source, in-browser API client for REST, GraphQL, and WebSocket requests.
- [Insomnia](https://insomnia.rest) - Open-source API client for testing REST, GraphQL, and gRPC requests.
- [IT-Tools](https://it-tools.tech) - Open-source, self-hostable collection of everyday developer utilities.
- [JSON Crack](https://jsoncrack.com) - Open-source visualizer that renders JSON, YAML, and CSV as node graphs.
- [JSONPlaceholder](https://jsonplaceholder.typicode.com) - Fake REST API for testing and prototyping front-end applications.
- [Regex101](https://regex101.com) - Editor for building, testing, and debugging regular expressions.
- [Slugme.io](https://slugme.io) — A smart, 100% client-side URL slug generator. Flattens accents, handles multi-language structures (English, Arabic, French, Spanish), and instantly builds clean, SEO-friendly URLs as you type.
- [Transform.tools](https://transform.tools) - Converter between formats such as JSON to TypeScript and SVG to React.

## Design and UI/UX

- [Arabify.io](https://arabify.io) — A free, browser-based Arabic calligraphy studio and logo maker. Type Arabic text with full harakat, choose from 13 authentic hands (Kufic, Naskh, Diwani), and export transparent images or animated video.
- [Coolors](https://coolors.co) - Color palette generator with quick iteration and export.
- [Fontsource](https://fontsource.org) - Open-source web fonts packaged as npm modules for self-hosting.
- [Google Fonts](https://fonts.google.com) - Library of open-source web fonts with easy embedding.
- [Iconify](https://iconify.design) - Framework providing over 100,000 open-source vector icons from many sets.
- [Khatly.com](https://khatly.com) - Arabic calligraphy generator with full diacritics and multiple traditional typefaces.
- [Lucide](https://lucide.dev) - Open-source icon set with a consistent stroke style.
- [Penpot](https://penpot.app) - Open-source design and prototyping platform for teams.
- [Realtime Colors](https://realtimecolors.com) - Preview of color palettes and typography on a live sample layout.
- [Tailwind UI Colors](https://uicolors.app) - Generator for Tailwind CSS color scales from a single hex value.
- [Unsplash](https://unsplash.com) - Library of freely usable high-resolution stock photographs.

## Productivity and Workflow

- [CarteVisite.io](https://cartevisite.io) - Browser-based maker for double-sided business cards with logo import and vCard QR codes.
- [Cviya.com](https://cviya.com) — A completely free, ATS-friendly professional resume builder. Features AI-assisted writing, flexible template layouts, unlimited downloads, no watermarks, and native multi-language/RTL support.
- [CyberChef](https://gchq.github.io/CyberChef/) - Open-source web app for encoding, encryption, compression, and data analysis.
- [Draw.io](https://app.diagrams.net) - Open-source diagramming tool for flowcharts and system architecture.
- [Excalidraw](https://excalidraw.com) - Virtual whiteboard for sketching diagrams with a hand-drawn style.
- [Falah.io](https://falah.io) — A free, open-source Islamic toolkit (Quran explorer, prayer times, Hijri calendar, Qibla finder, Zakat & inheritance calculators). Runs 100% client-side with no ads, no accounts, and no location tracking.
- [Obsidian](https://obsidian.md) - Markdown knowledge base that stores notes as local plain-text files.
- [Photopea](https://www.photopea.com) - Browser-based image editor that opens PSD, AI, and Sketch files.
- [QrFast.io](https://qrfast.io) — A lightning-fast, zero-tracking QR code generator. Create highly customizable QR codes (URL, WiFi, vCard, WhatsApp) with custom dot styling, center logos, and vector SVG exports. See the [QR Code Engineering Guide](https://github.com/abdessamadbettal/qr-code-engineering-guide) for how QR matrix generation actually works.
- [Stirling PDF](https://stirlingpdf.io) - Open-source, self-hostable toolkit for PDF operations such as merge, split, and convert.

## Hosting and Deployment

- [Cloudflare Pages](https://pages.cloudflare.com) - Static site hosting on a global CDN with serverless functions.
- [GitHub Pages](https://pages.github.com) - Static site hosting served from a GitHub repository.
- [Netlify](https://www.netlify.com) - Hosting for static sites and front-ends with built-in CI/CD.
- [Render](https://render.com) - Hosting for static sites, web services, and databases with a free tier.
- [Vercel](https://vercel.com) - Hosting for front-end frameworks and serverless functions.
